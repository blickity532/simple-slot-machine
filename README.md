# Simple Slot Machine (C#)

A simple slot machine game written in C#. This project simulates a classic slot machine experience in the console, allowing users to spin and try their luck!

## Features

- Console-based slot machine simulation
- Randomized reels and symbols
- Simple betting system
- Win/loss detection and payout calculation

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (Core or later)

### Running the Game

1. Clone this repository:
    ```bash
    git clone https://github.com/blickity532/simple-slot-machine.git
    cd simple-slot-machine
    ```

2. Build and run the project:
    ```bash
    dotnet run
    ```
    *(If the code is in a subdirectory like `SimpleSlotMachine`, cd into that folder first)*

## How to Play

- Follow the on-screen instructions to place your bet and spin the reels.
- Try to match symbols to win.
- The game keeps track of your credits as you play.
